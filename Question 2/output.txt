Validation (cost equals independent two-queue Huffman, Kraft sum = 1, prefix-free): 500/500 random tests passed

Time complexity analysis
  Building the min-heap of n leaves   : O(n)
  n-1 merges, each = 2 extract-min + 1 insert = 3 * O(log n) : O(n log n)
  Computing code lengths from the tree: O(n)
  Sorting symbols by (length, symbol) for the canonical codebook: O(n log n)
  Total T(n) = O(n log n), space = O(n)
  Correctness: the two least frequent symbols can always be siblings at the deepest level (greedy choice property)
