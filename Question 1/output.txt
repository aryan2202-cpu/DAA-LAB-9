Q1: Fractional Knapsack with Deterioration Rate
Input: arrays v[], w[], lambda[] (struct Item), capacity W, consumption time t
Model: an item consumed at time t has density v/w - lambda*t, items with density <= 0 are never taken

Validation against brute force over all item orders: 500/500 random tests matched

Time complexity analysis
  Computing effective densities       : O(n)
  Sorting by effective density        : O(n log n)
  Single greedy pass filling capacity : O(n)
  Total T(n) = O(n) + O(n log n) + O(n) = O(n log n), space = O(n)
  Correctness: swapping a taken item with a lower density item can only reduce the value (exchange argument)
