Validation (cost equals O(n^3) interval DP optimum, Kraft sum = 1, codes ordered and prefix-free): 3000/3000 random tests passed

Time complexity analysis
  Phase 1 (combination): n-1 rounds, each round scans the working list once to find the cheapest compatible pair (two smallest weights between consecutive terminal leaves) : O(n) per round
  Phase 2 (level assignment): one top-down pass over the 2n-1 nodes of the merge tree : O(n)
  Phase 3 (reconstruction): one pass assigning alphabetic codes from the leaf depths : O(n)
  Total T(n) = (n-1) * O(n) + O(n) + O(n) = O(n^2) for this simulation, space = O(n)
  Replacing the scan with a priority queue structure gives the classical O(n log n) Hu-Tucker bound
  Correctness: Hu and Tucker proved that the leaf depths of the combination tree are the depths of an optimal alphabetic tree
